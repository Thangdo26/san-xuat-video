# Travel short videos (Remotion)

Vertical 9:16 travel videos rendered with [Remotion](https://remotion.dev).
One composition renders every video; each video is a folder of data.

Current video: **`da-nang-3n2d`** — Đà Nẵng 3 ngày 2 đêm, 8 scenes, 73.5s.

## Layout

```
data/videos/<slug>/
  brief.md          goal, audience, tone, content rules
  video.json        the video: scenes, text, photos, map, music  ← edit this
  voiceover.json    generated by video:voice - clips, lengths, word timings
  credits.json      photo sources and licences

public/videos/<slug>/
  images/  food/    photos referenced by video.json
  map/region.jpg    region map plate, made by video:map
  voice/            generated voice-over clips
public/shared/music/ background music, made by video:music

src/
  schema.ts         the shape of video.json and voiceover.json
  TravelShort.tsx   scenes in a TransitionSeries, music with ducking
  Scene.tsx         map intro + gallery + subtitles + layout + voice
  MapIntro.tsx      zoom into a pin on the map plate
  Gallery.tsx       photos with Ken Burns and crossfades
  Subtitles.tsx     burned-in subtitles from word timings
  layouts.tsx       text layouts: hook, point, food, outro
  MapPlate.tsx      build-time only: renders the map plate with MapLibre
  Root.tsx          registers the compositions

scripts/            the npm commands below
output/<slug>/      draft.mp4, final.mp4, description.md (git-ignored)
```

Components decide **how** things look; the data decides **what** is shown.
Edit `video.json` by hand; never edit `voiceover.json` - regenerate it.

## Commands

```bash
# Everything, reusing what already exists: music → map → voice → validate
# → render draft.mp4 → description.md
npm run video:pipeline -- --slug da-nang-3n2d
npm run video:pipeline -- --slug da-nang-3n2d --final   # writes final.mp4

# Individual stages
npm run video:validate    -- --slug da-nang-3n2d   # no network
npm run video:voice       -- --slug da-nang-3n2d   # [--dry-run]
npm run video:import-voice -- --slug da-nang-3n2d --dir <folder>   # Vbee clips
npm run video:map         -- --slug da-nang-3n2d   # after changing map.*
npm run video:render      -- --slug da-nang-3n2d   # [--final] [--crf 20]
npm run video:description -- --slug da-nang-3n2d
npm run video:music -- --out shared/music/travel-upbeat --seconds 120 [--style upbeat|ambient] [--seed 1]
npm run video:fetch-image -- --slug da-nang-3n2d --dir images \
  --slot 02c-son-tra --title "File:Lady Buddha Statue at Linh Ung Pagoda.jpg"

npm run dev    # Studio preview
npm run lint   # eslint + tsc
```

Nothing uploads or publishes. `final.mp4` is only written with `--final`.

## Voice-over and subtitles

`video:voice` reads each scene's `narration`, makes one MP3 per scene and
writes `voiceover.json` with the clip path, its measured length and the time
of every word. Scenes shorter than their clip are lengthened in `video.json`.
Only clips whose narration or narrator settings changed are regenerated.

The engine is chosen in `video.json`:

```json
"narrator": { "provider": "edge", "voice": "vi-VN-HoaiMyNeural", "rate": "+10%" }
```

| provider | key | word timings | notes |
| --- | --- | --- | --- |
| `edge` | none | yes | Free Microsoft Edge read-aloud voices (`vi-VN-HoaiMyNeural`, `vi-VN-NamMinhNeural`). Unofficial endpoint: fine for drafts. For commercial publishing use Azure Speech, which has the same voices officially. |
| `elevenlabs` | `ELEVENLABS_API_KEY`, voice id in `narrator.voice` or `ELEVENLABS_VOICE_ID` | no | Without timings there are no subtitles and food photos switch at even intervals. |
| `vbee` | none here (clips are made in Vbee Studio) | estimated | Native Vietnamese voices in every region. `narrator.voice` is the Vbee voice code, e.g. `hn_female_ngochuyen_full_24k-stl`. See below. |

### Vbee

Vbee's API spends API credit, bought separately from the Studio points a new
account gets, so clips are made by hand in Vbee Studio: one request per scene
with exactly that scene's `narration`, downloaded as `<scene-id>.mp3` into one
folder. Then:

```bash
npm run video:import-voice -- --slug da-nang-3n2d --dir path/to/folder
```

It copies the clips into `public/`, writes `voiceover.json`, and refits every
scene to its clip, shorter as well as longer. Vbee returns no word timings,
so `scripts/lib/align.mjs` estimates them: it finds the pause at each comma
or full stop in the audio and spreads the words of each phrase over it.
Subtitles and food photos land within a word or so. Change a scene's
narration and its clip must be remade in Studio; `video:validate` warns
until it is.

Word timings drive the subtitles (`"subtitles": false` turns them off) and
switch each food photo when its dish is named. If the narration words for a
dish differ from its `name`, set `spokenAs`.

The `edge` provider uses `@andresaya/edge-tts`, licensed GPL-3.0. It is a
build tool only; the audio it produces is not covered by that licence.

## Map

`video.json` → `map` describes one region plate (center, zoom, size, style).
`video:map` renders it once with MapLibre and OpenFreeMap tiles; the video
then zooms over that image, so renders need no network. A scene's
`"map": { "lng", "lat", "name" }` zooms in and drops a pin there. Take
coordinates from OpenStreetMap (e.g. nominatim.openstreetmap.org) so pins
line up with the map. Validation fails if a pin is too close to the plate edge.

## Music

`video:music` synthesises the track from code, so there is no licence to
clear. It is deterministic for a given `--seed`. `--style upbeat` (default)
is C–G–Am–F at 118 BPM with four-on-the-floor kick, claps, pumping bass and a
plucked hook; `--style ambient` is the calm Fmaj7–G–Em7–Am7 loop at 92 BPM.
`music.volume` sets its level; it ducks to half while someone is speaking.

## Where to eat

A `"point"` scene can list up to three `dishes` (`name`, `place`,
`address`, optional `image` and `spokenAs`). When the narration reaches the
first one, the points and tip fade out and an "ĂN GẦN ĐÂY" list takes their
place; a dish with an `image` swaps in its photo as it is named.
`video:description` lists each stop's places under it, with Maps links.

## Adding a video

1. `mkdir data/videos/<slug>`, write `brief.md` and `video.json`
   (copy da-nang-3n2d and follow `src/schema.ts`; `id` must equal `<slug>`).
2. Add photos with `video:fetch-image`, then **look at every one** - Commons
   titles are not proof of what a photo shows.
3. Set `map` and run `video:map` if the video uses map intros.
4. `npm run video:pipeline -- --slug <slug>`.

## Review checklist

- [ ] **Nội dung** — places, itinerary, proper nouns and facts are correct
- [ ] **Quán ăn** — addresses checked on Google Maps; ratings only if verified
- [ ] **Footage** — each photo matches the place being talked about
- [ ] **Voice** — natural Vietnamese, proper nouns right, nothing cut off
- [ ] **Phụ đề** — spelling correct, in time with the voice
- [ ] **Khung hình** — 9:16, subject and captions clear of the TikTok UI
- [ ] **Âm thanh** — voice above the music, no clipping, sensible fades
- [ ] **Xuất file** — MP4 opens, full length, no black frames
- [ ] **Bản quyền** — photo credits and map attribution posted (description.md)
